# DayZ Doctor

Finds what breaks a DayZ server before the players do, and builds a per-server fix mod for DayZ 1.30.

DayZ Doctor, a Beer Garden collaboration. Engine by Overlord. Desktop app by Elon.
1.30 scanner by Look4orion, used under the MIT license.

## Download
Click `DayZDoctor_Setup_x.y.z.exe` in the file list above, then the download button, and run it.
Do not use "Code > Download ZIP" - download the installer on its own.

Windows SmartScreen warns the first time (the program is not code-signed): More info -> Run anyway.

Your servers and fix mods are kept in `%LocalAppData%\DayZDoctor`, so updates never lose them.
The app updates itself: when a new version is out it shows a pop-up with "Update now".
